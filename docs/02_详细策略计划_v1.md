# 02 美股尾盘超跌反转策略：详细计划 v1.0

> 这是回测之前写的计划。实际实现时有几处调整，见文末“实现时的调整”。

## 一、策略概述

| 项目 | 内容 |
|---|---|
| 策略类型 | 短期均值回归（隔夜到次日尾盘） |
| 核心假设 | 没有基本面消息、单纯因为流动性或情绪超跌的大盘股，次日有正的超额收益 |
| 股票池 | 标普 500 当日成分股 |
| 持仓周期 | 约 1 个交易日（尾盘买入，次日尾盘卖出） |
| 持仓数量 | 0–30 支，由信号强度决定，不强制买满 |
| 资金使用 | 多头总仓位最高 100%，不加杠杆；可选用 SPY 空头对冲 |

## 二、每日操作时间表

美国 2026 年 11 月 1 日结束夏令时，北京时间会相应推后 1 小时。尾盘操作落在北京时间凌晨，**强烈建议全程程序化**，人工只负责监控。

| 美东时间 | 北京时间（夏令时 / 冬令时） | 任务 |
|---|---|---|
| 前一交易日收盘后 | 早上 | 更新成分股、财报日历、除息日；计算 β、σ、ADV（日均成交额）、行业分类 |
| 09:30–15:20 | 21:30–03:20 / 22:30–04:20 | 盘中记录开盘跳空和累计成交量，标记重大新闻 |
| **15:20** | 03:20 / 04:20 | 取 15:20 快照，计算信号，生成**卖出单**（上一轮持仓） |
| **15:25** | 03:25 / 04:25 | 生成**买入单**，比较新旧持仓，只交易差额部分 |
| 15:25–15:50 | 03:25–03:50 / 04:25–04:50 | 按 VWAP 分批执行买卖 |
| 15:50 | 03:50 / 04:50 | 剩余未成交部分改用 MOC（收盘价市价单）；NYSE 的 MOC 截止时间是 15:50 |
| 收盘后 | 早上 | 对账，记录成交价、滑点、盈亏归因 |

## 三、数据准备

| 数据 | 用途 | 要求 |
|---|---|---|
| 历史成分股名单 | 确定每天的股票池 | **按日期记录当时的成分股**，避免幸存者偏差 |
| 日线 OHLCV | 计算 β、σ、ADV | 使用复权价格 |
| 日内 5 分钟或 30 分钟 K 线 | 取 15:20 价格、计算累计成交量 | 至少 2015 年至今 |
| 财报日历 | 过滤财报股 | 需要区分盘前（BMO）和盘后（AMC） |
| 除息日 | 过滤除息造成的"假跌" | |
| GICS 行业分类 | 行业分散、行业残差 | |
| SPY 与 11 个行业 ETF | 计算 β 和对冲 | |
| VIX | 判断市场状态 | |

## 四、信号计算

在第 t 天 15:20，对每支股票 i 计算：

```
① 日内收益    r_i  = P_i(15:20) / C_i(t-1) − 1
   大盘收益    r_m  = SPY(15:20) / SPY_close(t-1) − 1
② β_i        = 过去 60 天日收益对 SPY 回归的斜率，截断在 [0.3, 2.5]
③ 残差收益    e_i  = r_i − β_i × r_m
④ 残差波动    σ_i  = 过去 60 天日残差收益的标准差
⑤ 信号值      z_i  = e_i / σ_i
```

备选版本：把 ③ 里的 SPY 换成股票所属的行业 ETF，得到行业残差，两个版本都要回测。

## 五、过滤规则

| 编号 | 规则 | 默认处理 | 是否做对比测试 |
|---|---|---|---|
| F1 | 过去 20 天 ADV 低于 5000 万美元 | 剔除 | 否 |
| F2 | 财报时间落在 [t-1 盘后, t 盘中] 之间 | 剔除 | 是（单独统计财报股组） |
| F3 | 财报在 t+1 盘前公布（隔夜持有会碰上财报） | 剔除 | 否 |
| F4 | 当天是除息日 | 剔除 | 否 |
| F5 | 跳空幅度 O_t/C_{t-1} − 1 ≤ −3%，且 15:20 价格低于开盘价 | 标记为"新闻型下跌" | **是，重点对比** |
| F6 | 截至 15:20 的累计成交量，超过 20 日同时段均值的 4 倍 | 剔除 | 是（阈值测 3、4、6 倍） |
| F7 | 当天停牌过，或有并购、诉讼、FDA、下调指引等公告 | 剔除 | 否 |
| F8 | 截至 t 已连续下跌 5 天以上 | 保留 | 是 |

## 六、选股规则

```
候选 = 通过过滤的股票中，满足 z_i ≤ −2.0 且 e_i ≤ −2% 的
排序 = 按 z_i 从小到大（跌得越"异常"越靠前）
约束 = 同一 GICS 行业最多 5 支
数量 = 最多取 30 支；候选少于 30 支时有几支买几支，0 支就空仓
```

## 七、仓位分配

1. **按波动率倒数分配权重**：`w_i = (1/σ_i) / Σ(1/σ_j)`
2. **依次施加上限**：单支 ≤ 总资金 5%；单个行业 ≤ 25%；单支仓位 ≤ 其 ADV 的 0.5%
3. **结果**：只有 6 支入选时，总仓位最多约 30%，其余持有现金。信号少就少买。
4. **对冲（B 版本）**：同时做空 SPY，金额为 Σ(w_i × β_i) × 总资金。A（不对冲）和 B（对冲）两个版本都要回测。

## 八、卖出规则

| 规则 | 默认值 | 需要测试的变体 |
|---|---|---|
| 正常卖出 | t+1 日 15:25–15:50 按 VWAP 卖出 | 次日开盘卖出；持有 2、3、5 天 |
| 重复入选 | 继续持有，只调整到新的目标权重 | 全部卖出后重新买入（用来对比成本） |
| 止盈 | 不设 | 次日盘中涨到 +3% 提前卖出 |
| 个股止损 | 不设（均值回归策略设止损通常会降低收益） | 次日再跌 5% 卖出 |
| 突发事件 | 持仓股盘中出现并购、诉讼等重大公告，人工判断是否提前卖出 | — |

## 九、风险控制

**市场状态**

| 条件 | 处理 |
|---|---|
| VIX 在 30 到 45 之间 | 总仓位减半 |
| VIX 超过 45 | 停止开新仓，只卖出已有持仓 |
| SPY 当日 15:20 跌幅 ≤ −3% | 总仓位减半（需要测试：普跌日到底是机会还是陷阱） |

**策略回撤**

| 条件 | 处理 |
|---|---|
| 从净值高点回撤超过 10% | 总仓位减半 |
| 回撤超过 20% | 暂停策略，全面复查 |
| 单日亏损超过 3% | 第二天暂停开新仓 |
| 连续 20 个交易日净收益为负 | 触发复查 |

**执行层面**：下单前检查数据（价格不能是 0、涨跌幅不能超过 ±50%、报价时间戳不能超过 5 分钟前）；断网或行情源中断时，不下新单，只执行已有的卖出计划。

## 十、交易成本模型

```
单边成本(bp) = 佣金 + 半个买卖价差 + 市场冲击
市场冲击     ≈ 0.1 × σ_日 × √(交易额 / ADV)
```

回测分三档：**5bp、10bp、20bp（单边）**。每年约 250 次完整换仓，单边 10bp 意味着每年约 **50%** 的资金被成本吃掉。策略要能在 10bp 这一档依然明显赚钱，才值得考虑实盘。

## 十一、回测计划

- **阶段 0 数据检查**：成分股是否按历史日期变化；复权是否正确；日内数据是否缺失。
- **阶段 1 基准版本**：你原来的规则（全天跌幅前 30 名，收盘价买、次日收盘价卖）。只看“理想上限”，有前视偏差。
- **阶段 2 实盘可行版本**：15:20 计算信号，之后成交，加上成本；和阶段 1 对比前视偏差。
- **阶段 3 逐项加过滤条件**：每次只加一条，每条都要单独证明有用。
- **阶段 4 参数网格**：z 阈值 −1.5/−2.0/−2.5/−3.0；最大持股数 10/20/30；持有期 隔夜/1/2/3/5 天；残差基准 SPY/行业 ETF；对冲 开/关；等权/波动率倒数。
- **数据切分**：训练 2015–2019（调参）；验证 2020–2022（选方案）；最终测试 2023 至今（只跑一次）。
- **阶段 5 稳健性**：按年份、VIX 高低、行业分别统计；相邻参数表现要稳定；测试资金容量。

## 十二、上线标准（全部满足才进入模拟盘）

| 指标 | 标准 |
|---|---|
| 扣除 10bp 成本后的年化收益 | 高于 SPY（不对冲版本），或高于 8%（对冲版本） |
| 扣除成本后的夏普比率 | 不对冲 ≥ 0.8，对冲 ≥ 1.0 |
| 最大回撤 | ≤ 20% |
| 年度胜率 | 至少 70% 的年份是正收益 |
| 测试期表现 | 测试期夏普至少达到训练期的 50% |
| 单笔平均净收益 | 至少是单边成本的 2 倍 |

## 十三、上线步骤

1. 模拟盘 2–3 个月，对比模拟成交价和回测假设的滑点。
2. 小资金实盘：先用计划资金的 10%–20%，运行 3 个月。
3. 逐步加仓：实盘夏普达到回测的 60% 以上、没有触发风控，每季度资金翻倍。
4. 持续监控：每月检查滚动 60 天夏普和胜率；连续 3 个月低于回测 5% 分位就暂停复查。

## 十四、每日记录字段

日期、候选数、入选数、每支股票的 z 值与过滤原因、目标权重与实际权重、成交价与 VWAP 的偏差、当日收益（拆成大盘部分 β × r_m 和残差部分）、风控是否触发。

## 实现时的调整

| 计划 | 实现 | 原因 |
|---|---|---|
| 15:20 信号、VWAP 执行 | 15:30 信号、MOC 收盘价成交 | 免费的 60 分钟线在 15:30 有整点价格；MOC 对小账户最简单、没有价差 |
| 5 分钟/30 分钟线，2015 年起 | 雅虎 60 分钟线，只有约 730 天 | 免费数据的限制；更早年份用收盘价信号近似，并量化了前视偏差 |
| 训练期 2015–2019 | 训练期 2011–2019 | 日线数据从 2010 年开始，样本更多 |
| 成本 5/10/20bp 三档 | 零成本 / 机构 5bp / 小账户（IBKR 阶梯佣金 + 1 万美元示例规模） | 小账户的每笔最低佣金才是真实约束 |
| F7 重大新闻过滤 | 未实现 | 没有免费的历史新闻数据；F5 跳空过滤部分替代 |
| 回撤暂停后“全面复查” | 影子净值回撤修复到 10% 以内自动恢复 | 回测里需要一个可执行的恢复规则 |
| 止盈/止损变体 | 未测 | 核心信号本身没有超额，止盈止损不会改变结论 |
