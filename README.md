# 标普 500 尾盘超跌反转策略

每天美东 15:30 找出标普 500 里跌得最多的股票，收盘前买入，第二天收盘前卖出。
这个仓库包含这次研究的全部内容：最初的设想、完善后的计划、代码、数据缓存、回测结果和报告。

> **结论：在标普 500 里，这个策略扣除交易成本后不赚钱，没有通过上线标准。**
> 程序默认只做模拟跟踪，只生成订单清单，不会自动下单。

| 入选股票次日相对 SPY 的超额（零成本，每笔平均） | 训练 2011–19 | 验证 2020–22 | 测试 2023–26 | 15:30 真实信号 2023-10 起 |
|---|---|---|---|---|
| 原始设想：跌幅前 30 只 | −0.5bp | +0.1bp | +4.4bp | +5.1bp |
| 原始设想：跌超 5% | −4.3bp | −22.0bp | +13.3bp | +13.5bp |
| 计划规格（残差 z≤−2、剔除财报等） | −5.1bp | −14.0bp | −0.5bp | −1.0bp |

- 来回交易一次的成本：机构约 10bp，1 万美元的 IBKR 小账户约 20–25bp（每笔最低佣金固定，账户越小越贵）。
- 15:30 真实信号（2023-10 至 2026-09），按 1 万美元小账户的成本：原始设想年化 −43.6%，计划规格 −8.9%，同期 SPY +25.1%。
- 2011–2026 年 SPY 有 55% 的交易日上涨，大跌股票第二天上涨的概率只有 52–53%。
- 96 组参数网格里，训练期最好的一组到了验证期就变成负的。

## 运行

需要 Python 3.8+，以及 pandas、numpy、pyyaml、requests、lxml。

```
cd reversal
python scripts/update_data.py             # 先下载雅虎行情（日线 2010 起、60 分钟线近 730 天），约 5–10 分钟
python scripts/run_backtest.py            # 回测，约 2 分钟 → results/report.html
python scripts/run_backtest.py --grid     # 加参数网格，约 20 分钟
python scripts/live_signal.py             # 美东 15:30–15:45 运行：当天信号 + MOC 订单清单
python scripts/paper_track.py             # 模拟盘净值
```

雅虎的 60 分钟线只保留最近约 730 天，所以以后下载时，“15:30 真实信号”回测的时间窗口会和仓库里的结果（2023-10-31 至 2026-09-28）不同；日线部分可以复现。

原本放在 qsys 项目里（`~/quant/reversal/`），在那里会用 qsys 的 venv 和 `../data/meta/tbill_3m.csv`；仓库里已附带一份 `reversal/data/meta/tbill_3m.csv`，可以独立运行。

## 说明

- 数据来自雅虎财经、SEC EDGAR、fja05680/sp500、维基百科、新浪、Nasdaq。仓库不包含雅虎的原始行情，只包含由它计算出的回测统计。
- 回测结果不代表未来收益，不构成投资建议。
